# picofunc — YD-RP2040 簡易ファンクションジェネレータ / インバータ信号源

- ファームウェア: `src/`（PlatformIO, arduino-pico, 200 MHz）
- 操作 UI（PC / Android 共通の Web アプリ）: `web/` → https://arobberwhothreatenswithpunch.github.io/picofunc/
- PC アプリ: **`fgen_gui.bat` をダブルクリック** → `pc/launch_web.py` が `web/` を `http://127.0.0.1:8765/` で配信し、
  Chrome（なければ Edge）のアプリ窓で開く。窓を閉じるとサーバーも終了する。必要なのは Python 3 のみ（追加パッケージ不要）
- 旧 PC 版 GUI（tkinter、CH1 / CH2 のみ）: `python pc/fgen_gui.py`（pyserial が必要）

## 操作画面（オシロ風）
- 上部ステータスバー: 表示中チャンネルの V/div、時間軸、トリガ状態、Run / Stop
- 時間軸: 既定は自動（トリガソースの見える繰り返しが 3 周期以上入る。インバータのスイッチング表示はキャリア基準）。
  **画面の右端クリック = 拡大、左端 = 縮小**（マウスホイールも可）で手動に切り替わる。「水平」キーまたは H 表示のクリックでメニュー
- Auto Scale: 選択中の発生器（Gen1 → CH1、Gen2 → CH2、インバータ → U）でトリガし、時間軸を自動に戻す
- 補間表示（表示メニュー、既定 ON）: インバータ運転中は、状態応答の合間をファームウェアと同じ加減速規則で予測して滑らかに描く
- トリガ: **右端の T マーカーを上下にドラッグ = レベル**（手動になる）、**上端の ▼ を左右にドラッグ = トリガ位置**。トリガメニューで中央に戻せる
- タッチ（タブレット / スマホ）: 端のタップは指のずれ 24 px まで許容、マーカーの当たり判定 28 px。
  **2 本指のピンチで時間軸（FFT 画面ではスパン）を拡大・縮小**。マーカーは動かしたときだけ値が変わる
- 表示は接続中なら実際の出力どおり（出力 OFF = 0 V、インバータ OFF = SD Low で 0 V、IDLE = 全脚 50 %）。
  設定値を見たいときは 表示メニュー → 設定プレビュー
- 取込モード（表示メニュー）: 自動 = スイッチング波形が詰まるほど縮小したら包絡線を薄くして平均波形を重ねる（Hi-Res 表示）/ ノーマル / 高分解能
- 前面パネル: Run/Stop・Auto Scale、チャンネル 1〜4・M（押すとメニュー、もう一度で非表示）、
  測定・カーソル・FFT・トリガ・表示・Utility、信号発生 Gen1 / Gen2 / Inverter（押すと設定パネルとメニューを切替）
- ソフトキー（画面下 6 個）: 押したキーのメニュー。▼ の項目は選択肢、数値はポップアップで入力
- 表示は、ファームウェアと同じ計算によるシミュレーション（実測ではない）

| 表示モード | 1 黄 | 2 緑 | 3 青 | 4 桃 | M 紫 |
|---|---|---|---|---|---|
| 信号源（Gen1 / Gen2） | GP0 PWM | CH2 差動 | GP2 (+) | GP3 (−) | — |
| インバータ 3 相 | U | V | W | — | 線間 U−V（V−W・W−U も表示可） |
| インバータ 単相 | A | B | — | — | A−B |

- インバータは「平均（RC 後）」と「スイッチング波形」を切り替えられる（FFT でキャリアの側波帯を見るときはスイッチング）
- 自動測定（最大 8 個）: 周波数・周期・デューティ・パルス幅・Vpp・最大/最小・平均・実効値・位相差。統計（平均/最小/最大）表示あり
- カーソル: X（Δt・1/Δt）、Y（ΔV）。画面をドラッグして移動
- FFT: 65536 点、窓関数 Hann / 矩形 / Flat top / Blackman-Harris、上位 5 ピーク表示（dBV、1 Vrms = 0 dBV）。
  スパンは「自動（基本波の 25 次まで）」または 0〜100 Hz … 50 MHz。記録時間はスパンから決まり（サンプリング = 4 × スパン）、
  画面の時間軸とは独立。キャリア（と側波帯）が表示スパンより上なら局所平均でサンプリングし、折り返しを出さない。
  **FFT 画面の左右クリック = スパン（右で狭く）、上下クリック = dB/div（上で拡大）**、ホイールでスパン

## 配線表

| GPIO | 機能 | 備考 |
|---|---|---|
| GP0 | CH1 PWM 出力 | 0.1 Hz〜10 MHz |
| GP1 | CH1 反転出力 | |
| GP2 / GP3 | CH2 波形 差動 + / − | 試験的。各ピンに RC ローパスを付ける |
| **GP4** | **U 相 IN**（単相では脚 A） | IR2302 IN。slice 2 |
| **GP6** | **V 相 IN**（単相では脚 B） | slice 3 |
| **GP8** | **W 相 IN** | slice 4。単相では Low 固定 |
| **GP10** | **SD（3 個共通、負論理）** | **外部 10 kΩ で GND へプルダウン**（リセット中も停止させるため） |
| **GP11** | **非常停止スイッチ** | 押すと GND。内部プルアップ。未接続なら常に「正常」 |
| GP23 | WS2812B | 緑=CH1、青=CH2、橙=インバータ動作中、赤=異常停止 |

- IR2302: IN=High でハイサイド ON、IN=Low でローサイド ON。デッドタイム（約 540 ns）はドライバが内蔵している。
- 単相（オーディオ）: U・V の 2 脚でフルブリッジを組み、負荷（スピーカー）は脚 A と脚 B の間につなぐ。
- 信号 GND は、パワー側 GND の 1 点で共通にする。

## インバータの仕様

| 項目 | 値 |
|---|---|
| キャリア | 10〜120 kHz、三角波（phase-correct）、3 脚同期 |
| 基本波 | 1〜1500 Hz（3 相 SPWM / 単相ユニポーラ） |
| 制約 | **キャリア ≥ 8 × 基本波**（オーディオは 8 × 帯域）。満たさない指令は拒否 |
| 振幅 m | 0〜0.8（超える指令は拒否）。`INV LIMIT UNLOCK`（UI の「上限解除」）で 0.99 まで。USB 切断・再起動で 0.8 に戻る。0→目標値へ 2.0/s でランプ |
| 正弦テーブル | 1024 点（Q15）、32 bit 位相アキュムレータ |
| duty 制限 | 下限 max(2 %, 1 µs × fc) ／ 上限はその対称。ブートストラップ充電とデッドタイムの確保 |
| 直流励磁 | 3 相のみ。m ≤ 0.3、タイムアウト 1〜60 s（既定 10 s）、角度の変化は 90°/s |
| オーディオ | 単相のみ。UI でファイルを変換（DC 除去、帯域 = キャリア/8 で低域通過、再サンプル）して USB で送り続ける |

### 起動・停止の手順（ファームウェアで強制）
1. 電源投入直後: SD=Low、全 IN=Low
2. 有効化: 全 IN=Low（全ローサイド ON）のまま SD=High → 10 ms 待ってブートストラップを充電 → 全脚 50 %（出力 0 V）の IDLE
3. 停止 / 無効化: m を 0 までランプしてから IDLE、または SD=Low
4. **非常停止**: 割り込みで即座に SD=Low、PWM 停止、FAULT を保持。スイッチを戻して「有効化」で復帰
5. **自動停止**: USB 切断（アプリを閉じる・ケーブルが抜ける）で無効化。ファームウェアが固まった場合は、ウォッチドッグ（500 ms）でリセットされ SD=Low になる

## コマンド一覧（USB シリアル 115200、1 行 1 コマンド）

| コマンド | 内容 |
|---|---|
| `ID` / `STATUS` | 機器情報 / 全チャネルの状態 |
| `PWM <Hz> <duty%>` / `PWM OFF` | CH1 |
| `WAVE <SINE\|TRI\|SAW\|SQR> <Hz> [amp%] [ofs%]` / `WAVE OFF` | CH2 |
| `INV STATUS` | インバータの状態 |
| `INV MODE <3P\|1P>` | 3 相 / 単相（OFF のときのみ） |
| `INV CARRIER <Hz>` | キャリア 10000〜120000（OFF / IDLE のとき） |
| `INV ENABLE` / `INV DISABLE` | 有効化（プリチャージ付き）/ 無効化 |
| `INV RUN <f Hz> <m> [加速度 Hz/s]` | 正弦波運転。周波数は加速度で、m は 2.0/s で変化する |
| `INV STOP` | m→0 にして IDLE へ |
| `INV DIR <FWD\|REV>` | 相順（停止中のみ） |
| `INV LIMIT <NORMAL\|UNLOCK>` | 振幅 m の上限 0.8 / 0.99（UNLOCK は USB 切断で解除） |
| `INV DC <deg> <m> [timeout s]` | 直流励磁（3P、m ≤ 0.3） |
| `INV AUDIO START <fs> <bw> <m>` / `INV AUDIO STOP` | 音声ストリーム開始（再送すると音量だけ変更）/ 停止 |
| バイナリ `0x02 0x5A len_lo len_hi <int16 PCM> sum_lo sum_hi` | 音声データ（最大 4096 byte / フレーム、sum = ペイロードの 16 bit 和。壊れたフレームは破棄） |

応答は `OK INV state=RUN mode=3P fc=20000.0 f=50.000 m=0.300 theta=… sd=1 fault=NONE …`、エラーは `ERR INV <理由>`、イベントは `EVT INV FAULT ESTOP` などの形式。

## オシロでの確認手順（母線電源をつなぐ前に）
1. GP4 / GP6 / GP8 に RC ローパス（例: 10 kΩ + 100 nF、fc ≈ 160 Hz）を付け、3 ch で観測する。
2. UI で 3 相・キャリア 20 kHz・基本波 10 Hz・m 0.5 → 有効化 → 運転。
3. 確認する内容
   - 3 本の正弦波が **120° ずつ** ずれているか（U → V → W の順。逆転で U → W → V）
   - 周波数が指令どおりか（10 Hz → 周期 100 ms）
   - 振幅: RC 後の電圧が 3.3 V × (0.5 ± m/2) になるか（m=0.5 なら約 0.83〜2.48 V）
   - フィルタなしで 1 本を見て、キャリア周波数と、duty 制限（120 kHz で 12〜88 %）を確認
4. SD（GP10）: 有効化で High、無効化・USB 切断・非常停止で Low になるか
5. 非常停止: GP11 を GND に落とす → 即座に SD=Low、UI に赤帯が出る → 戻して「有効化」で復帰するか
6. 単相: U・V の差（A−B）をオシロの演算で見る。正弦波運転と音声再生の両方で確認する

その後、母線電圧を下げた状態（数 V）、m を小さくした状態から負荷試験を始める。

## 注意
- IGBT（K40H1203 級）は 100 kHz を超えるとスイッチング損失とテール電流で発熱が増える。温度を見ながら使う。
- デッドタイム 540 ns は 120 kHz では周期の約 6.5 % に当たり、波形の歪み（特にオーディオ）の原因になる。
- 直流励磁は、巻線抵抗だけで電流が決まる。空芯コイルでは、交流より大きな電流になりやすいので、m を小さくして短時間で使う。
- 音声ストリーミング中は、アプリを前面に表示したままにする（バックグラウンドでは送信が止まり無音になる）。
